# جدول ویرایش‌پذیری PIXVA (مرحله ۵)

راهنما: هر ردیف فقط بر اساس کد واقعی پر شده است. «ویرایش بصری» یعنی پس از ذخیره، خروجی سمت سرور عوض می‌شود — نه صرفاً وجود داشتن ظاهر.

پیش‌نیاز عمومی: Elementor رایگان برای ویرایشگر؛ بدون Elementor، قالب بدون هیچ خطایی کار می‌کند و همه بخش‌ها با شورت‌کد قابل ویرایش‌اند.
