## ۸) موارد باقی‌مانده و وابستگی‌های Elementor Pro

1. **سند/زنجیرهٔ چهارم «استایل‌دهی صفحات» (`docs/pixva-elementor-themes.md`)** — پیاده‌سازی نشد (ledger: PXV-E6). سبک پایه توسط قالب و تب Style ویجت‌ها تأمین می‌شود.
2. **Elementor Pro لازم است بر:** قالب‌های آرشیو/تک‌مقاله/بلاگ (Theme Builder)، پاپ‌آپ‌ها، فرم‌های پیشرفتهٔ Pro، شرطی‌سازی فرم‌ها.
3. **تبدیل‌نشده بر اساس تصمیم:** صفحات حساب کاربری (۱۸–۲۲)، ابزارهای تشخیص/قیمت/پیکسل (۸–۱۰ — عمداً با کدهای امن/سقفی خودشان).
4. **جداول سفارش‌دار حرفه‌ای‌تر** (مرتب‌سازی ستونی، ذخیرهٔ نمای کاربر) — پیشنهادی، فاز بعد.
5. **بررسی رفتار موبایل ادمین روی دستگاه واقعی** — اسکرین‌شات‌ها دسکتاپ/ریسپانسیو شبیه‌سازی‌شده‌اند.
