قالب بلوکی استاندارد مرکز تعمیر تلویزیون و نمایشگر پیکسوا. راست‌چین، فارسی، بدون jQuery و بدون وابستگی به افزونه.

== Description ==

محاسبه‌گر هزینه تعمیر با نرخ‌نامه ۱۴۰۵ سمت سرور، پیگیری آنلاین با کد و شماره، پایگاه کدهای خطا، نرخ‌نامه شفاف، اسلایدر قبل/بعد، مجله سئومحور و اسکیما JSON-LD.

فونت وزیرمتن (Vazirmatn) با مجوز OFL در assets/fonts قرار دارد. متن مجوز: assets/fonts/OFL.txt

ساختار بلوکی: templates/‎، parts/‎، patterns/‎، styles/‎، theme.json.

== Installation ==

1. پوشه pixva را در wp-content/themes آپلود کنید یا فایل zip را از پیشخوان (نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته) نصب کنید.
2. قالب را فعال کنید.
3. در اولین فعال‌سازی، برگه‌ها (خانه، مجله، محاسبه هزینه، پیگیری، کدهای خطا، نرخ‌نامه، درباره، تماس، سوالات متداول)، منو، خدمات، ۲۴ برند، نمونه‌کار و شش مقاله ساخته می‌شوند.
4. آدرس کارگاه، ساعت‌ها، محدوده اعزام و مختصات نقشه را از سفارشی‌ساز تنظیم کنید.
5. نرخ‌ها را از پیشخوان ← پیگیری تعمیرات ← نرخ‌نامه ویرایش کنید.

پرونده نمونه پیگیری کد PXV-DEMO-2401 و شماره 09121111111 دارد (هر دو با هم لازم است). قبل از استفاده واقعی آن را حذف کنید.
