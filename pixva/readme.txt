پلتفرم تشخیص، تعمیر، دانش، ثبت درخواست، پیگیری و گارانتی تعمیر تلویزیون. راست‌چین، بدون jQuery، بدون فریم‌ورک JS و بدون وابستگی به افزونه.

== Description ==

چرخه محصول: مشکل ← شناسایی دستگاه ← تشخیص ← توضیح ← برآورد (فقط با قیمت‌گذاری تنظیم‌شده) ← ثبت درخواست ← تعمیر ← پیگیری ← گارانتی ← بازگشت به دانش و ابزارها.

* تشخیص مرحله‌ای (برند، مدل، مشکل، نشانه‌ها، اطلاعات تکمیلی) با زبان «محتمل / ممکن / نیاز به بررسی»؛ بدون JS هم کار می‌کند.
* برآورد هزینه فقط از جدول قیمت‌گذاری قابل تنظیم؛ اگر تنظیم نشده باشد صادقانه «نیاز به بررسی» نشان می‌دهد و ثبت درخواست ممکن است.
* پایگاه کدهای خطا (کد، برند، مدل، معنی، نشانه‌ها، علت‌ها، شدت، بررسی ایمن، اقدام تخصصی، خدمت و مقاله مرتبط) با جست‌وجو و فیلتر.
* تست پیکسل تمام‌صفحه (سیاه، سفید، قرمز، سبز، آبی، خاکستری، گرادیان) با صفحه‌کلید و احترام به کاهش حرکت.
* ثبت درخواست امن: nonce، honeypot، محدودیت نرخ، جلوگیری از ارسال تکراری، آپلود تصویر خصوصی با بررسی محتوای واقعی فایل.
* پیگیری با کد + شماره همراه، بدون نمایش اطلاعات شخصی یا یادداشت داخلی، با قفل تلاش ناموفق.
* گارانتی فقط بر اساس سیاست تنظیم‌شده؛ هیچ مدتی ساخته نمی‌شود.
* حساب مشتری (/account/) و داشبورد نقش‌محور (/dashboard/) با قابلیت‌های اختصاصی و کمترین دسترسی.
* سئو: عنوان، توضیح، canonical، robots، Open Graph، اسکیمای صادقانه، نقشه سایت بدون صفحات noindex/ریدایرکت/۴۱۰، مدیر ریدایرکت بدون زنجیره و حلقه.
* لایه آنالیتیکس مستقل از سرویس‌دهنده (dataLayer و رویداد pixva:track) بدون اطلاعات شخصی.

فونت وزیرمتن (Vazirmatn) با مجوز OFL در assets/fonts قرار دارد. متن مجوز: assets/fonts/OFL.txt

== Installation ==

1. پوشه pixva را در wp-content/themes آپلود کنید یا فایل zip را از پیشخوان نصب کنید.
2. قالب را فعال کنید. صفحه‌های مسیرهای اصلی (ابزارها، تشخیص، برآورد، تست پیکسل، تعمیر، ثبت درخواست، پیگیری، گارانتی، درباره، تماس، پرسش‌ها، حساب، داشبورد) ساخته یا به قالب درست وصل می‌شوند و ساختار پیوند یکتا /blog/%postname%/ می‌شود.
3. از «پیکسوا ← اطلاعات کسب‌وکار» فقط اطلاعات واقعی (تلفن، نشانی، ساعات، شیوه‌های پذیرش، سیاست گارانتی) را وارد کنید. هر فیلد خالی در سایت نمایش داده نمی‌شود.
4. از «پیکسوا ← قیمت‌گذاری» در صورت تمایل جدول برآورد را تنظیم کنید. تا تنظیم نشود، هیچ قیمتی نمایش داده نمی‌شود.
5. خدمات، برندها، مدل‌ها، کدهای خطا، نمونه‌کارها و پرسش‌ها را از پیشخوان اضافه کنید. آرشیوهای خالی تا داشتن محتوا noindex می‌مانند.

== Upgrade from 1.x ==

ارتقا خودکار و بدون حذف داده است: برگه‌های تکراری پیش‌نویس می‌شوند، نشانی‌های قدیمی ۳۰۱ یا ۴۱۰ می‌گیرند، اطلاعات ساختگی نسخه قبل وارد تنظیمات نمی‌شود و گزارش کامل در «پیکسوا ← گزارش ارتقا» نمایش داده می‌شود.
