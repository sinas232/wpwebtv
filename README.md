# پیکسوا (pixva) — نسخه ۱٫۳٫۰

قالب بلوکی استاندارد وردپرس برای مرکز تخصصی تعمیر تلویزیون و نمایشگر. راست‌چین، فارسی، بدون jQuery و بدون وابستگی به افزونه.

پوشه قابل نصب `pixva/` است. فایل آماده بارگذاری در پیشخوان: [`dist/pixva.zip`](dist/pixva.zip) (کپی هم‌نام نسخه: [`pixva-1.3.0.zip`](pixva-1.3.0.zip)).

## نصب

1. [`dist/pixva.zip`](dist/pixva.zip) را دانلود کنید.
2. در پیشخوان وردپرس بروید به **نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته**.
3. zip را انتخاب و نصب کنید، سپس فعال کنید. داخل زیپ فقط پوشه `pixva` است و `style.css` دقیقاً در `pixva/style.css` قرار دارد.
4. با فعال‌سازی، برگه‌های خانه، مجله، محاسبه هزینه، پیگیری، کدهای خطا، نرخ‌نامه، درباره، تماس و سوالات متداول، به‌همراه خدمات، هر ۲۴ برند، نمونه‌کار و شش مقاله واقعی عیب‌یابی ساخته می‌شوند.
5. آدرس کارگاه، ساعت‌ها، محدوده اعزام و مختصات نقشه را از **سفارشی‌ساز** تنظیم کنید.
6. نرخ‌ها را از **پیشخوان ← پیگیری تعمیرات ← نرخ‌نامه** ویرایش کنید (سطح ۱۴۰۵).

پرونده نمونه پیگیری کد `PXV-DEMO-2401` و شماره `09121111111` دارد؛ هر دو با هم لازم است. قبل از استفاده واقعی آن را از پیشخوان حذف کنید.

## داخل قالب

- محاسبه‌گر هزینه با نرخ‌نامه ۱۴۰۵ سمت سرور، جستجوی برند، ثبت نوبت و کد پیگیری
- سامانه پیگیری آنلاین (کد PXV به‌علاوه شماره همان پرونده)
- پایگاه کدهای خطای چشمک چراغ با ارجاع برند بدون کد به محاسبه‌گر
- برگه نرخ‌نامه شفاف، اسلایدر قبل/بعد، مجله، سوالات متداول و اسکیما JSON-LD
- ساختار بلوکی: `templates/`‎، `parts/`‎، `patterns/`‎، `styles/`‎، `theme.json`
- فونت وزیرمتن، راست‌چین، بدون jQuery، انیمیشن ملایم با احترام به `prefers-reduced-motion`
