# پیکسوا (pixva)

قالب اختصاصی وردپرس برای مرکز تعمیر تلویزیون و نمایشگر. راست‌چین، بدون jQuery و بدون وابستگی به افزونه.

پوشه قابل نصب `pixva/` است. فایل آماده بارگذاری در پیشخوان: [`dist/pixva.zip`](dist/pixva.zip).

## نصب

1. [`dist/pixva.zip`](dist/pixva.zip) را دانلود کنید.
2. در پیشخوان وردپرس بروید به **نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته**.
3. zip را انتخاب و نصب کنید، سپس فعال کنید.
4. با فعال‌سازی، برگه‌های محاسبه‌گر، پیگیری، کدهای خطا، تماس، درباره و سوالات متداول، به‌همراه خدمات، برندها، نمونه‌کار و دو مقاله ساخته می‌شوند.
5. شماره تماس، لوگو، نماد اعتماد و ترتیب سکشن‌های صفحه اصلی را از **سفارشی‌ساز** تنظیم کنید.

پرونده نمونه پیگیری کد `PXV-DEMO-2401` و شماره `09121111111` دارد. قبل از استفاده واقعی آن را از پیشخوان حذف کنید.

## داخل قالب

- محاسبه‌گر هزینه تعمیر (برند، تکنولوژی، سایز، نوع خرابی) با ثبت نوبت و کد پیگیری
- سامانه پیگیری آنلاین وضعیت تعمیر
- پایگاه کدهای خطای چشمک چراغ
- اسلایدر قبل/بعد، مجله، سوالات متداول و اسکیما JSON-LD
- فونت وزیرمتن، راست‌چین، بدون jQuery
